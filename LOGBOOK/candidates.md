## 2026-08-22 (streamer role)

- Pattern now confirmed twice, ready for notes.md: a bare `router.use(guard)` is scoped to wherever the *router* is mounted, not to the specific paths the guard is meant to protect. v1.3.0's channels feature had an *old* blanket guard (`auth.requireViewAccessApi`, mounted on the whole proxy) break a *new* per-resource check that ran after it. This session's streamer role had the mirror case: a *new* guard (`auth.requireStreamerOrAdmin`) placed as a bare `router.use()` on a router mounted at `app.use('/api', ...)` blocked *old*, unrelated routes (`/api/state`, `/api/admin/*`) it was never meant to touch. Both times the fix was the same: scope the guard to a sub-router mounted at the router.use() with the exact path it is supposed to protect — `routes/channels.js`'s `/channels/mine` sub-router already did this correctly and should have been checked against before writing `routes/streamer.js`'s first version. Caught by the full test suite both times, not by manual testing or code review. (trigger: out-of-band, source: feat-streamer-role decision 2026-08-22, agent: claude-code)
- Streamer self-service (`/streams/mine`) exposes no way to edit `sharedWith` — same reasoning already logged for channels' admin-create form: it needs a user picker a non-admin should not see. If a streamer ever needs to grant a specific viewer access to one of their private streams, this needs a scoped-down version of admin.js's access-grant modal. (trigger: out-of-scope, source: feat-streamer-role decision 2026-08-22, agent: claude-code)
- The viewer page's Programme/Layout/Sources/Audio-monitor sidebar and the cinema/normal view-mode toggle were removed in the same session as the streamer role (unrelated to it, but touching the same files) — `docs/CONFIGURATION.md`'s `screenshots/viewer-cinema.png` and `viewer-audio.png` now show UI that no longer exists in that exact form (no separate audio-monitor row, no Cinema button). The prose was rewritten but the screenshots themselves were not regenerated. (trigger: out-of-scope, source: viewer-page-simplification, agent: claude-code)
